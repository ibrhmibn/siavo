# SIAVO — Sistem Informasi Aspirasi dan Advokasi Online

Platform pengaduan & advokasi mahasiswa. Jembatan digital antara mahasiswa dan institusi kampus.

> **"Suara Mahasiswa, Aksi Nyata"**

## 🎯 Fitur

### Guest
- Landing page dengan statistik real-time
- Pusat Informasi (SOP, Panduan, Beasiswa, FAQ)
- Daftar Kegiatan SEMA & SIAVO

### Mahasiswa
- Kirim aspirasi + upload bukti
- Tracking laporan via nomor tiket
- Edit profil

### Admin (SEMA/BEM)
- Verifikasi laporan
- Update status + upload bukti formal PDF
- Rekap laporan dengan grafik
- Kelola artikel, pengumuman, kegiatan, user

## 🛠️ Tech Stack

- **Backend:** PHP 8.2 (Native)
- **Database:** MariaDB 10.4
- **Frontend:** HTML5, CSS3, Vanilla JS
- **Framework:** Bootstrap 5.3
- **Library:** Font Awesome 6, Chart.js 4
